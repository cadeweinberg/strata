## Agreed scope

Headless Linux SBC based on MPFS025 in FCVG484, with a common-PCB population
path to MPFS095/160/250. Include system DDR, removable Linux storage, Ethernet,
PCIe expansion, programming/debug access, and CPU GPIO / FPGA expansion.
Reserve a board-edge region for later display hardware. Initial FPGA GPU work
is compute and off-screen rendering, toward a Vulkan implementation without
window-system integration (WSI). Conformance is a future hardware/driver goal,
not a requirement for first-board bring-up. OpenGL through Zink is a later
software possibility, contingent on Vulkan features.

MPFS460 requires a different package/board. Upgrades mean device-specific
bitstreams and assembly options, not a shared bitstream or hot-swappable chip.
No schematic, stackup, memory part, or complete BOM has been selected yet.
